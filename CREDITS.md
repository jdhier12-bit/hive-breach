# Credits — Hive Breach

All 3D models, textures, music, icons, and code in this game are original
works created for Hive Breach. Nothing was copied from another game.

## 3D models
Designed and built in Blender (headless) as original meshes, then exported to
glTF / GLB. Aliens, turrets, the Aegis mech, the crashed hive ship, the
colony base, and the arena were all authored for this project. No third-party
geometry was used.

## Textures
Ground, path, warning stripes, pad decal, metal, glow, and burst sprites were
generated for this project.

## Music
The theme loop (`assets/music/theme.mp3`) was composed and rendered for this
project.

## Sound effects
Generated at runtime with the Web Audio API.

## Font

See `assets/fonts/OFL.txt`.

## Engine
[three.js](https://threejs.org/) r170 (MIT License) is vendored in `lib/`.
